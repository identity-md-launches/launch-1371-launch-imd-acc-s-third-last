Integration Snippet · Uniswap v4 Hook 
// 1. Once during setup: approve the immutable Stacker contract
IERC20(imd).approve(address(stacker), type(uint256).max);

// 2. Inside afterSwap: extract 25-100 bps from your existing trade fee
uint256 cashback = imdSideAmount * RATE_BPS / 10_000;

// 3. Credit trader directly; always handle fallback so the trade NEVER reverts
try stacker.credit(trader, cashback) {
    // Success: trader now holds sIMD shares earning yield!
} catch {
    // Fallback: send plain IMD directly to the trader
    IERC20(imd).transfer(trader, cashback);
}
Developer Spec

The 7 Rules of Integration

Key principles every project hook must follow to safely participate in imd/acc.

1

Fund From Your Existing Fee

Pick a rate between 0.25% and 1.0% (25-100 bps) and deduct it on the IMD side of your existing fee. Never charge extra fees to traders.

2

Never Break a Trade

Always wrap stacker.credit() in a try / catch block. If the call fails for any reason, transfer plain IMD to the trader.

3

Credit The Real Trader

Read the trader address from router hookData, fall back to sender, and never use tx.origin.

4

Check Gas Upfront

Ensure the swap has sufficient gas for credit() before executing, preventing wallets from estimating cheap paths without cashback.

5

Budget the Gas Cost

Mainnet credit costs ~130k gas for a new trader and ~96k for repeat traders. Wallets should send estimates × 1.3.

6

Uniswap v4 Whitelist

Include standard afterSwap logic that frontend whitelisting expects, support router msgSender, and guard copycat pools.

7

Test Failure Paths

Test your fallback on Sepolia using TestSIMD's pausing function to ensure your hook gracefully falls back to plain IMD.
